PROJECT_01
Router DHCP Configuration

Configured a Cisco router to act as a DHCP server, automatically assigning IP addresses to end devices across a network. Demonstrated dynamic host configuration and verified successful IP allocation to clients.

  • Configured DHCP address pools with appropriate network ranges, default gateways, and DNS settings
  • Excluded static IP ranges from the DHCP pool to prevent address conflicts with servers and network devices
  • Verified DHCP lease assignments using show ip dhcp binding and ipconfig on end devices
  • Tested connectivity between dynamically assigned hosts across the network

PROJECT_03
Medium Business Enterprise Network with Port Security

Designed and implemented a full enterprise network for a medium-sized business with multiple departments. Applied VLAN segmentation, inter-VLAN routing, and port security controls — this is the capstone final year project.

  • Designed a three-tier network topology (access, distribution, core) with department-level VLAN segmentation
  • Configured Router-on-a-Stick inter-VLAN routing to allow controlled communication between departments
  • Implemented port security on access layer switches to limit MAC addresses per port and prevent unauthorised device connections
  • Set up GRE tunnels and RIPv2 dynamic routing to connect geographically separate office branches
  • Configured VTP for centralised VLAN management across multiple switches
  • Produced full network documentation including IP addressing scheme and topology diagram
